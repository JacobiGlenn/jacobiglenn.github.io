---
title: "Learning Python outside the classroom changed how I approach programming"
date: "02/2026"
excerpt: "ICS 31 gave me the foundation, but building something I actually wanted is what made it stick."
---
<p>My intro Python class at UCI — ICS 31 — was great. Menu-driven apps, logic exercises, a fake In-N-Out drive-through program. I learned a lot. But everything lived in the terminal and none of it was mine.</p>

<p>The font cycler project changed that. I had a real goal: make my GitHub README header cycle through dozens of fonts with a scramble effect in between. No tutorial covered exactly what I wanted, so I had to figure it out from documentation and trial and error.</p>

<p>The setbacks were real. Pillow handles fonts differently than I expected — TTF files have to be located correctly or the whole thing silently falls back to a default font and you don't realize it for an hour. Getting the transparent GIF output right took multiple complete rewrites.</p>

<p>But working through those problems made concepts click in a way that assignments never did. I understood why list comprehensions are useful. I actually cared about the difference between frame duration types. I read documentation on purpose instead of because I had to.</p>

<p>That project pushed me toward what I do now: write out the goal first, think before touching the keyboard, and treat programming as a design problem before it's a code problem.</p>
